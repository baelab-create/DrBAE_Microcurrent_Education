## 자료 해석

파형 그림은 실측 데이터가 아닌 교육용 개념도입니다. 세포 연구와 제품의 인체 효과는 구분합니다. 제품 개발 계보는 개발자 제공 설명에 근거합니다. 법률 적합성을 보증하는 문서는 아닙니다.

논문 도판의 권리는 원권리자에게 있습니다. Fig. 1은 해당 연구를 설명하는 맥락에서 출처와 함께 인용했습니다. 외부 홍보물로 전재하거나 공개할 경우 별도 권리 검토가 필요합니다.
